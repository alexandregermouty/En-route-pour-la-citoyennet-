# Parcours citoyen 2026

Application pédagogique bilingue français–anglais fondée sur le *Livret du citoyen* (édition mai 2026). Elle propose 14 modules couvrant les cinq parties et les annexes, 47 notions, 28 questions corrigées et un bilan de progression.

## Ouvrir l’application

Ouvrez `index.html` dans un navigateur. Aucun compte ni serveur n’est nécessaire. Le changement FR/EN est immédiat, y compris pendant un exercice. La progression est conservée dans le stockage local du navigateur utilisé.

## Publier sur GitHub Pages

1. Créez un nouveau dépôt GitHub.
2. Téléversez **le contenu de ce dossier** à la racine du dépôt. `index.html` doit se trouver à la racine, à côté de `app.js`.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis **main** et **/(root)**.
4. GitHub affichera l’adresse du site après la première publication.

## Sources

Les leçons et exercices sont des adaptations pédagogiques originales. Les images recadrées proviennent du *Livret du citoyen*, ministère de l’Intérieur, édition mai 2026, fourni pour ce projet. Chaque leçon indique sa page source et renvoie au PDF officiel. Pour toute règle ou démarche actuelle, vérifiez le site public compétent.

## English

Upload the **contents** of this folder to the root of a new GitHub repository, keeping `index.html` at the top level. In **Settings → Pages**, select **Deploy from a branch → main → /(root)**. Progress is stored locally in the learner's browser.
